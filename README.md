고려대학교 중어중문학과 「교양중국어」 강의를 소개하고 운영하는 웹사이트입니다.
**서버 없이** `index.html`을 더블클릭하면 바로 열리는 정적 사이트입니다.

> ⚠️ **배포하기 전에 꼭 하세요**
> 1. 관리자 비밀번호를 바꾸세요. 처음 비밀번호는 공개 문서에 적지 않습니다(관리자가 따로 보관). (아래 [3-1](#3-1-로그인과-비밀번호))
> 2. `index.html` 맨 위 설정의 예시 값(교수자 이름·연락처·강의실·날짜·숫자)을 실제 정보로 바꾸세요.

## 2. 파일 구성

사이트는 **`index.html` 파일 하나**입니다. 이 파일만 있으면 어디서든 열리고, 이 파일만 올리면 배포가 끝납니다.

```
index.html          ★ 사이트 전체 (아래 세 부분으로 되어 있음)
README.md           이 안내서 (배포할 필요 없음)
_분리본_백업/        합치기 전의 분리된 파일들 (보관용 — 필요 없으면 지워도 됩니다)
```

`index.html` 안의 구성 (메모장·VS Code로 열면 큰 제목 주석으로 구분되어 있습니다)

| 위치 | 내용 | 고칠 일 |
|---|---|---|
| ① 맨 위 `<script id="site-config">` | 사이트 설정 — 모든 글·메뉴·일정·퀴즈·관리자 비밀번호 해시 | **여기만 고치면 됩니다** |
| ② `<style>` | 디자인. 맨 위 `:root` 의 색상 값으로 전체 색을 바꿀 수 있음 | 색을 바꿀 때만 |
| ③ 맨 아래 `<script>` | 동작 코드 (커리큘럼·달력, 참여 기능, 실시간 퀴즈, 화면 그리기, 팝업·폭죽, 관리자 화면) | 보통은 없음 |

## 3. 내용 고치는 두 가지 방법

### 방법 A — 관리자 화면에서 (추천)

1. 사이트 오른쪽 위 **자물쇠(🔒)** 를 누르고 비밀번호를 입력합니다.
2. **사이트 편집** 탭에서 섹션(기본 정보, 첫 화면, 커리큘럼 …)을 고르고 칸을 고칩니다.
   - 목록 항목은 `↑ ↓ ✕` 로 순서를 바꾸거나 지우고, `+ 추가` 로 늘립니다.
   - 주차에 과제를 새로 넣으려면 그 주차를 펼쳐 `+ 과제` 를 누릅니다.
3. **적용하기** 를 누르면 *이 브라우저에서만* 바뀐 모습이 보입니다.
4. 마음에 들면 **설정 파일 → index.html 내려받기** 를 눌러 파일을 받고,
   사이트의 `index.html` 을 이 파일로 **바꿔서 다시 올리면** 모든 방문자에게 반영됩니다.

> 💡 "적용하기"만 하고 index.html을 올리지 않으면, 다른 사람에게는 바뀐 내용이 보이지 않습니다.
> 관리자 화면 위쪽에 **"이 브라우저 편집본 적용 중"** 이 보이면 아직 올리지 않은 편집본이 있다는 뜻입니다.
> 받은 index.html은 **설정 파일 → 파일 고르기** 로 언제든 그 안의 설정을 다시 불러올 수 있습니다.

### 방법 B — index.html을 직접 고치기

메모장이나 VS Code로 `index.html`을 열어 맨 위 **① 사이트 설정** 부분에서 **따옴표 안의 글만** 바꾸고 저장한 뒤 새로고침합니다.
항목을 늘리거나 줄일 때는 `{ ... }` 덩어리를 통째로 복사·삭제하고 사이의 쉼표(,)를 맞춰 주세요.
페이지가 하얗게 나오면 쉼표나 따옴표가 빠졌을 가능성이 큽니다.

### 3-1. 로그인과 비밀번호

- 처음 비밀번호: 공개 문서에는 적지 않습니다. 사이트를 만든 사람에게 따로 확인하세요.
- 바꾸는 법: 관리자 화면 → **설정 파일** → **관리자 비밀번호 변경** → 새 비밀번호(8자 이상) 입력
  → **index.html 내려받기** → 사이트의 index.html 교체.
- 코드에는 비밀번호 원문이 없고 `admin.passwordHash` (SHA-256 해시값)만 저장됩니다.
- 5번 틀리면 30초 동안 잠깁니다. 브라우저 탭을 닫으면 자동으로 로그아웃됩니다.

### 3-2. 관리자 화면 메뉴

| 탭 | 하는 일 |
|---|---|
| 대시보드 | 신청·명단·출석·과제·투표·공지 개수. **예시 기록 만들기**로 화면을 시험해 볼 수 있음 |
| 사이트 편집 | 모든 섹션의 글·목록을 화면에서 고치기 |
| 공지 | 공지 쓰기·수정·삭제, 중요/고정 표시 |
| 수강생 명단 | 한 명씩 추가, 엑셀에서 복사해 여러 명 붙여넣기, CSV 파일 불러오기, 명단 내려받기 |
| 회원가입 / 출석 / 과제 | 내역 표 보기 (비밀번호는 표시·저장되지 않음), 검색·주차별 보기, **엑셀 파일로 받기** (CSV, 엑셀에서 한글 그대로 열림) |
| API 키 | Anthropic(Claude)·BAZE 등 API 키 저장·보기·지우기, Claude 키 연결 확인, 다른 서비스 키 추가 |
| 설정 파일 | 설정이 담긴 index.html 저장·불러오기, 편집본 지우기, 비밀번호 변경 |

**API 키 관리**: 키는 관리자의 브라우저에만 저장되고, 설정 파일·index.html 내려받기·CSV에는 들어가지 않습니다.
그래서 다른 컴퓨터에서는 다시 입력해야 합니다. 공용 컴퓨터에서는 「이 브라우저에 기억」을 끄면 창을 닫을 때 지워집니다.
Anthropic 키는 퀴즈 AI 출제에 그대로 쓰입니다. BAZE 키는 저장만 해 두며, 코드에서는 `window.ApiKeys.get("baze")`로 꺼내 씁니다.

학생은 **회원가입한 아이디·비밀번호**로 "수강생 공간"에 로그인합니다. (5번 틀리면 30초 잠김)
**수강생 명단**을 등록하고 **명단 적용하기**를 누르면, 명단에 있는 학번·이름으로 가입한 계정만 로그인할 수 있습니다.
공개되는 index.html 설정에는 이름·학번 대신 해시값만 들어갑니다. 명단 원본은 관리자의 브라우저에만 남으니 **명단 받기**로 백업해 두세요.

## 4. 학생 기록은 어디에 저장되나요 (중요)

이 사이트는 서버가 없습니다. 그래서 기본 상태(미리보기 모드)에서는

- 투표, 회원가입, 출석, 과제 제출 기록이 **학생 본인의 브라우저(localStorage)** 에만 저장됩니다.
- 교수자에게 자동으로 전달되지 **않습니다.** 관리자 화면에는 *그 컴퓨터에 남은 기록*만 보입니다.
- 과제 파일은 이름과 제출 시각만 기록되고 파일 자체는 어디에도 올라가지 않습니다.

실제로 학생들의 기록을 모으려면 **접수 주소(endpoint)** 를 연결하세요.

### 4-1. Google 스프레드시트로 모으기 (Apps Script)

1. Google 스프레드시트를 새로 만듭니다.
2. **확장 프로그램 → Apps Script** 를 열고 아래 코드를 붙여넣고 저장합니다.
3. **배포 → 새 배포 → 유형: 웹 앱**, 실행 사용자: **나**, 액세스 권한: **모든 사용자** → 배포.
4. 나오는 **웹 앱 URL** 을 복사해 관리자 화면 → 사이트 편집 → 참여 기능 → **접수 주소** 에 붙여넣고 적용 → index.html 저장·교체.

이제 회원가입·출석·과제·투표가 시트의 `apply`, `attendance`, `submission`, `vote` 탭에 한 줄씩 쌓이고,
과제 파일은 Google Drive의 "교양중국어 과제 제출" 폴더에 저장됩니다.

```javascript
const FOLDER_NAME = "교양중국어 과제 제출";

function doPost(e) {
  const p = e.parameter;
  const ss = SpreadsheetApp.getActiveSpreadsheet();
  const sheet = ss.getSheetByName(p.type) || ss.insertSheet(p.type || "기타");

  // 과제 파일 → Drive 폴더에 저장
  let fileUrl = "";
  if (p.fileData) {
    const it = DriveApp.getFoldersByName(FOLDER_NAME);
    const folder = it.hasNext() ? it.next() : DriveApp.createFolder(FOLDER_NAME);
    const blob = Utilities.newBlob(Utilities.base64Decode(p.fileData), p.fileType, p.fileName);
    fileUrl = folder.createFile(blob).getUrl();
  }

  const data = Object.assign({}, p);
  delete data.fileData;
  if (fileUrl) data.fileUrl = fileUrl;

  // 첫 줄(머리글)에 없는 항목은 자동으로 추가
  const header = sheet.getLastRow() ? sheet.getRange(1, 1, 1, sheet.getLastColumn()).getValues()[0] : [];
  Object.keys(data).forEach(k => { if (header.indexOf(k) < 0) header.push(k); });
  sheet.getRange(1, 1, 1, header.length).setValues([header]);
  sheet.appendRow(header.map(h => (data[h] !== undefined ? data[h] : "")));

  return ContentService.createTextOutput("ok");
}
```

> 이 코드는 예시입니다. Google 계정에서 직접 실행해 보지는 못했으니, 처음 연결한 뒤
> 회원가입을 한 번 해서 시트에 줄이 생기는지 꼭 확인하세요.
> Formspree 같은 폼 접수 서비스 주소를 넣어도 됩니다. (파일은 base64 글자로 전송됩니다)

## 4-2. 실시간 퀴즈 (Kahoot·Socrative 방식)

**수업 전 — 문제 만들기** (관리자 화면 › 🎯 퀴즈 › + 새 퀴즈 만들기)
- 직접 쓰기: 문제, 선택지 4개, 정답(라디오 버튼), 제한 시간, 해설을 입력합니다.
- **AI 출제**: 범위(주차)를 고르고 문제 수·난이도·추가 요청을 정한 뒤
  - *방법 1* — Anthropic API 키를 넣고 **✨ Claude로 출제하기** (Claude Opus 5.5 사용, 사용량만큼 요금 발생).
    키는 이 브라우저에만 저장되고 설정 파일에는 들어가지 않습니다. API 키는 <https://console.anthropic.com> 에서 만듭니다.
  - *방법 2* — **📋 요청문 복사** → ChatGPT·Claude 웹 등에 붙여넣기 → 받은 답을 그대로 붙여넣고 **불러오기** (키 필요 없음).
  - AI가 만든 문제는 **반드시 읽어 보고 고친 뒤** 저장하세요. 형식이 맞지 않는 문제는 자동으로 빠집니다.
- 저장 후 '설정 파일 저장'으로 index.html을 올려 두면 다른 컴퓨터에서도 같은 퀴즈를 쓸 수 있습니다.

**수업 중 — 진행하기**
1. 교수자 컴퓨터(프로젝터)에서 관리자 로그인 → **참여하기 › 실시간 퀴즈 › 🎤 진행자 모드** 에서 퀴즈를 고르고 **퀴즈 방 열기**.
2. 화면에 **PIN 6자리와 QR**이 뜹니다. 학생은 휴대폰 카메라로 QR을 찍거나, 사이트에서 PIN을 입력해 들어옵니다.
3. 학생 이름이 화면에 모이면 **퀴즈 시작** → 문제마다 제한 시간이 흐르고, 모두 답하면 바로 정답이 공개됩니다.
   점수는 정답일 때 500점 + 빨리 답할수록 최대 500점이 더해집니다.
4. **순위 보기 → 다음 문제** 를 반복하고, 끝나면 시상대와 전체 순위가 나옵니다.
5. **결과 CSV 받기**로 학생별 선택·정오·점수·응답 시간과 문제별 정답률을 엑셀로 엽니다.
   결과는 관리자 화면 › 퀴즈 › 지난 퀴즈 결과에도 남습니다(이 브라우저, 최근 20개).

**꼭 알아 두세요**
- QR은 **배포된 사이트 주소**로 만들어집니다. 내 컴퓨터에서 연 파일(file://)이나 localhost 주소로는 학생 휴대폰이 들어올 수 없으니,
  배포한 사이트에서 진행하거나 `index.html` 설정의 `quiz.joinUrl` 에 배포 주소를 적으세요.
- 연결은 PeerJS(WebRTC)를 써서 **교수자 브라우저가 방장 역할**을 합니다. 별도 서버는 필요 없지만 교수자·학생 모두 인터넷이 되어야 하고,
  진행 중에는 교수자 화면(탭)을 닫지 마세요. 처음 연결할 때 PeerJS의 무료 공개 연결 서버(0.peerjs.com)를 거칩니다.
- 학교 와이파이가 이런 직접 연결(WebRTC)을 막으면 학생이 들어오지 못할 수 있습니다. 수업 전에 휴대폰 한 대로 미리 시험해 보세요.
  안 되면 휴대폰 데이터(LTE/5G)로 접속해 보세요.
- 학생이 새로고침하거나 잠깐 끊겨도 같은 휴대폰·같은 PIN으로 다시 들어오면 점수가 이어집니다.
- 수강생 공간에 로그인한 학생은 결과 CSV에 학번이 함께 기록됩니다.

- **📎 참고 자료 (반드시 참고):** 「✨ AI 생성」 창 위쪽에서 PDF · PPTX · DOCX · HWPX · XLSX/XLS · CSV · HTML · TXT 파일을 올리거나 끌어다 놓습니다.
  올린 자료의 글이 **강의 노트를 비롯한 그 주차의 모든 AI 생성 요청 맨 앞에** 들어가고, "자료의 어휘·문법·예문·순서를 우선하고 어긋나는 내용은 만들지 말 것"을 지시합니다.
  「모든 주차 공통 자료로 올리기」를 고르면(강의계획서 등) 모든 주차에 함께 쓰입니다. 파일 하나당 앞 40,000자, 한 번에 최대 120,000자까지 씁니다.
  - 옛 형식(.ppt · .doc · .hwp)은 읽을 수 없으니 .pptx · .docx · .hwpx 또는 PDF로 저장해 올리세요. 스캔한 PDF(글자가 그림)도 읽을 수 없습니다.
  - 자료 내용은 **관리자의 이 브라우저에만** 저장되고 index.html·학생 화면에는 들어가지 않습니다. 다른 컴퓨터에서는 다시 올려야 합니다.
- **만드는 중:** AI가 일하는 동안 창에 삽질하는 일꾼 애니메이션과 걸린 시간이 보입니다.
- **만드는 법:** 항목별 「✨ 만들기」 또는 「✨ 전체 한 번에 만들기」(1~3분). Anthropic API 키가 필요합니다. (관리자 화면 › 🔑 API 키, 또는 창 위쪽 칸에 입력)
- **API 키 없이:** 「📋 요청문」을 눌러 ChatGPT·Claude 웹 등에 붙여넣고, 받은 답(JSON)을 창 아래 「API 키 없이 만들기」 칸에 넣고 「적용」.
- **그림 바꾸기:** 「🎨 이 그림만 다시 그리기」, 또는 가진 그림 주소를 직접 넣고 「영상·노래·그림 주소 저장」.
- **TTS(읽어 주기):** 브라우저에 들어 있는 중국어 음성을 씁니다. 크롬·엣지·사파리·휴대폰은 대부분 중국어 음성이 있습니다.
- **모두에게 보이게 하기:** 만든 내용은 먼저 이 브라우저에만 적용됩니다. 관리자 화면 › 💾 설정 파일 › **index.html 내려받기** 후 사이트에 올리세요.
  15주를 모두 만들면 index.html이 1MB 안팎으로 커집니다 (정상).

## 5. 배포하기 (인터넷에 올리기)

**`index.html` 파일 하나만** 올리면 됩니다. (`README.md`, `_분리본_백업`, `.claude` 폴더는 올리지 않아도 됩니다)

### 방법 1 — Netlify Drop (가장 쉬움, 무료)
1. <https://app.netlify.com/drop> 에 접속해 로그인합니다.
2. `index.html` 하나만 든 폴더를 만들어 브라우저 창에 **끌어다 놓습니다**.
3. 주소(예: `https://○○○.netlify.app`)가 바로 생깁니다.
4. 내용을 바꾼 뒤에는 같은 사이트의 **Deploys** 화면에 그 폴더를 다시 끌어다 놓습니다.

### 방법 2 — GitHub Pages (무료)
1. GitHub에 새 저장소를 만들고 `index.html`을 올립니다. (저장소 맨 위에 있어야 함)
2. 저장소 **Settings → Pages → Branch: main / (root) → Save**.
3. 1~2분 뒤 `https://아이디.github.io/저장소이름/` 으로 열립니다.
4. 내용을 바꿀 때는 새 `index.html`로 덮어쓰기만 하면 됩니다.

### 방법 3 — 학교·학과 웹 서버
학과 홈페이지 서버나 FTP 공간이 있다면 `index.html`을 원하는 위치에 복사하면 됩니다. 특별한 서버 설정은 필요 없습니다.

> 배포 후에는 휴대폰으로도 한 번 열어 보세요. 바뀐 내용이 안 보이면 새로고침(또는 캐시 비우기)을 해 보세요.

## 7. 보안·개인정보 주의

- 관리자 화면은 **정적 사이트를 편하게 고치는 도구**이지 강력한 보안 장치가 아닙니다.
  비밀번호 해시는 공개 파일에 들어 있고, 페이지 코드는 누구나 볼 수 있습니다.
  **길고 추측하기 어려운 비밀번호**를 쓰고, 성적처럼 중요한 처리는 학교 LMS를 함께 쓰세요.
- 학생 로그인은 아이디·비밀번호 방식이지만, 서버가 없어서 계정이 **가입한 그 브라우저에만** 저장됩니다.
  다른 컴퓨터·휴대폰에서는 같은 아이디로 로그인할 수 없고, 브라우저 데이터를 지우면 계정도 사라집니다.
  여러 기기에서 쓰려면 계정을 보관할 서버(예: Google Apps Script + 시트, Firebase)가 필요합니다.
- 회원가입 양식에는 개인정보 동의 항목이 있습니다. 비밀번호는 원문 대신 해시값만 이 브라우저에 저장되며 접수처로도 보내지 않습니다. 실제 수집 시에는 학교의 개인정보 처리 기준에 맞게 문구를 고치세요.
- 엑셀로 내려받은 명단·신청 파일은 개인정보이니 공유 폴더에 두지 마세요.

## 8. 자주 생기는 문제

| 증상 | 해결 |
|---|---|
| 페이지가 하얗게 나온다 | index.html 설정의 쉼표·따옴표를 확인하세요. 관리자 화면 → 설정 파일 → 이전에 저장한 index.html을 불러와 되돌릴 수 있습니다. |
| 고친 내용이 다른 컴퓨터에서 안 보인다 | "적용하기"는 그 브라우저에만 반영됩니다. index.html을 내려받아 서버의 파일을 바꿔 주세요. |
| 관리자 비밀번호를 잊었다 | 비밀번호를 바꾸기 전에 받아 둔 index.html(또는 GitHub의 이전 버전)에서 `admin.passwordHash` 값을 가져와 지금 index.html에 넣으면, 그때의 비밀번호로 들어갈 수 있습니다. |
| 모든 과제가 "마감"으로 나온다 | 오늘 날짜가 학기 뒤라서 그렇습니다. 일정의 날짜를 새 학기로 바꾸거나, 테스트용 오늘 날짜로 확인하세요. |
| 학생이 퀴즈 PIN을 넣어도 "방을 찾을 수 없음" | 교수자 화면에서 방이 열려 있는지, PIN이 맞는지 확인하세요. 교수자 탭을 닫으면 방이 사라집니다. 학교 와이파이 문제일 수 있으니 휴대폰 데이터로도 시도해 보세요. |
| AI 출제에서 "API 키가 올바르지 않습니다" | 키를 다시 복사해 넣거나, 키 없이 '방법 2(요청문 복사)'를 쓰세요. |
| 글꼴이 다르게 보인다 | 인터넷이 없으면 Google 글꼴 대신 기본 글꼴로 보입니다. 정상입니다. |
